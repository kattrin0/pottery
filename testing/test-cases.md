## Аутентификация (AUTH)

| ID | Название | Приоритет | Предусловия | Шаги | Ожидаемый результат |
|---|---|---|---|---|---|
| **TC-AUTH-001** | Успешный вход по телефону и SMS-коду | 🔴 Critical | Пользователь не авторизован; номер зарегистрирован в системе; SMS-доставка работает | 1. Открыть сайт<br>2. Ввести валидный номер телефона (+7)<br>3. Нажать «Получить код»<br>4. Ввести корректный 4-значный код из SMS<br>5. Нажать «Войти» | Сессия создана; выполнен переход на экран «Расписание» (SCR-002); хедер с вкладками «Расписание» / «Мои записи» доступен |
| **TC-AUTH-002** | Автопереход при существующей сессии | 🔴 Critical | У пользователя есть действующий токен/сессия | 1. Открыть сайт | Экран входа (SCR-001) не показывается; сразу открывается SCR-002 |
| **TC-AUTH-003** | Активация CTA «Получить код» только при валидном телефоне | 🔴 Critical | Пользователь на шаге 1 входа | 1. Открыть SCR-001<br>2. Оставить поле «Телефон» пустым<br>3. Ввести неполный номер<br>4. Ввести полный валидный номер | Кнопка «Получить код» disabled при пустом/неполном номере; enabled при полном валидном номере |
| **TC-AUTH-004** | Переход на шаг 2 после отправки кода | 🔴 Critical | Пользователь на шаге 1; введён валидный телефон | 1. Нажать «Получить код» | Открывается шаг 2: поле «Код из SMS» (4 ячейки), текст «Мы отправили код на +7 …», таймер «Отправить код повторно (0:30)», ссылка «Изменить номер», кнопка «Войти» |
| **TC-AUTH-005** | Вход с неверным SMS-кодом | 🔴 Critical | Код отправлен на валидный номер | 1. Ввести неверный 4-значный код<br>2. Нажать «Войти» | Сообщение «Неверный код. Проверьте и введите ещё раз»; поле кода очищается; фокус на поле ввода; номер телефона сохранён; сессия не создана |
| **TC-AUTH-006** | Повторная отправка SMS после таймера | 🔴 Critical | Пользователь на шаге 2; код только что отправлен | 1. Дождаться окончания обратного отсчёта (30 сек)<br>2. Нажать «Отправить код повторно» | Ссылка активируется после таймера; новый код отправлен; таймер перезапускается |
| **TC-AUTH-007** | Блокировка повторной отправки во время таймера | 🔴 Critical | Пользователь на шаге 2; таймер активен | 1. Попытаться нажать «Отправить код повторно» до истечения таймера | Ссылка неактивна; повторная отправка не выполняется |
| **TC-AUTH-008** | Возврат к шагу 1 («Изменить номер») | 🔴 Critical | Пользователь на шаге 2 | 1. Нажать «Изменить номер» или «‹ Назад» | Возврат к шагу 1; ранее введённый номер сохранён в поле |
| **TC-AUTH-009** | Защита от двойной отправки при входе | 🔴 Critical | Пользователь на шаге 2; введён корректный код | 1. Нажать «Войти»<br>2. Повторно нажать «Войти» во время ожидания | CTA в состоянии Loading; поля заблокированы; повторный запрос не отправляется |
| **TC-AUTH-010** | Валидация: телефон не заполнен | 🔴 Critical | Пользователь на шаге 1 | 1. Оставить поле пустым<br>2. Попытаться нажать «Получить код» | CTA disabled; при принудительной валидации — «Введите номер телефона» |
| **TC-AUTH-011** | Валидация: неполный формат телефона | 🔴 Critical | Пользователь на шаге 1 | 1. Ввести неполный номер (например, +7 999 12_)<br>2. Попытаться отправить | Сообщение «Похоже, номер введён не полностью»; CTA disabled |
| **TC-AUTH-012** | Ошибка сети при отправке кода | 🔴 Critical | Сеть недоступна или API недоступен | 1. Ввести валидный телефон<br>2. Нажать «Получить код» | Заглушка/сообщение «Не удалось войти. Попробуйте ещё раз» + кнопка «Повторить» |
| **TC-AUTH-013** | Превышение лимита попыток ввода кода | 🔴 Critical | API возвращает ошибку rate limit | 1. Многократно ввести неверный код | Сообщение «Слишком много попыток. Попробуйте позже»; дальнейший ввод заблокирован |
| **TC-AUTH-014** | Кнопка «Войти» disabled до полного ввода кода | 🔴 Critical | Пользователь на шаге 2 | 1. Ввести 1–3 цифры кода | Кнопка «Войти» disabled; enabled только при 4 введённых цифрах |

## Просмотр расписания (SCH)

| ID | Название | Приоритет | Предусловия | Шаги | Ожидаемый результат |
|---|---|---|---|---|---|
| **TC-SCH-001** | Загрузка расписания на 7 дней по умолчанию | 🔴 Critical | Клиент авторизован; в API есть слоты на ближайшие 7 дней | 1. Открыть SCR-002 «Расписание» | Отображаются слоты на ближайшие 7 дней; сортировка по дате и времени (возрастание); состояние Loading → Content |
| **TC-SCH-002** | Карточка слота содержит все обязательные поля | 🔴 Critical | На SCR-002 загружен хотя бы один слот | 1. Просмотреть карточку слота | Видны: дата/время, программа, мастер (имя + фото), свободные места («N из M мест свободно»), цена, длительность, описание, адрес, статус (бейдж текст + форма) |
| **TC-SCH-003** | Отображение полностью занятого слота | 🔴 Critical | В API есть слот с free_seats = 0 | 1. Открыть SCR-002<br>2. Найти занятый слот | Карточка отображается (не скрывается); бейдж «Мест нет»; карточка кликабельна |
| **TC-SCH-004** | Empty state: нет слотов на период | 🔴 Critical | API возвращает пустой список слотов | 1. Открыть SCR-002 | Empty state: «Пока нет доступных занятий»; кнопка «Сбросить фильтры» не показывается (фильтры не активны) |
| **TC-SCH-005** | Переход к деталям слота | 🔴 Critical | На SCR-002 есть доступный слот | 1. Кликнуть по карточке слота | Открывается SCR-003 с полной детализацией слота |
| **TC-SCH-006** | Состояние Loading при загрузке расписания | 🔴 Critical | Клиент авторизован; данные ещё не загружены | 1. Открыть SCR-002 | Показаны скелетоны карточек (3–4 шт.); лента дат и фильтры доступны |
| **TC-SCH-007** | Ошибка загрузки расписания | 🔴 Critical | API недоступен или возвращает ошибку | 1. Открыть SCR-002 | Сообщение «Не удалось загрузить расписание. Попробуйте позже» + кнопка «Повторить» |
| **TC-SCH-008** | Повторная загрузка расписания | 🔴 Critical | SCR-002 в состоянии Content | 1. Нажать «Обновить» (или дождаться автообновления) | Список слотов перезапрашивается; данные актуализированы |
| **TC-SCH-009** | Отображение слота «Мало мест» | 🔴 Critical | В API есть слот с малым количеством свободных мест | 1. Открыть SCR-002 | Бейдж «Мало мест» (текст + форма, не только цвет) |
| **TC-SCH-010** | Отображение отменённого мастерской слота | 🔴 Critical | В API есть слот со статусом «отменён мастерской» | 1. Открыть SCR-002 | Бейдж «Отменено мастерской» + причина отмены из API |
| **TC-SCH-011** | Отображение фото мастера в карточке | 🔴 Critical | Слот привязан к мастеру с фото | 1. Просмотреть карточку слота | Фото мастера отображается рядом с именем |
| **TC-SCH-012** | Навигация: переход в «Мои записи» | 🔴 Critical | Клиент на SCR-002 | 1. Нажать вкладку «Мои записи» в хедере | Переход на SCR-005 |

## Фильтрация расписания (FIL)

| ID | Название | Приоритет | Предусловия | Шаги | Ожидаемый результат |
|---|---|---|---|---|---|
| **TC-FIL-001** | Открытие панели фильтров | 🔴 Critical | Клиент на SCR-002 | 1. Нажать «Фильтры» | Открывается BS-001 (панель/блок): дата, программа, toggle «Только со свободными местами» |
| **TC-FIL-002** | Фильтрация по программе «Лепка для новичков» | 🔴 Critical | BS-001 открыта; есть слоты обеих программ | 1. Выбрать чип «Лепка»<br>2. Нажать «Применить» | На SCR-002 только слоты программы «Лепка для новичков»; индикатор активных фильтров виден |
| **TC-FIL-003** | Фильтрация по программе «Гончарный круг» | 🔴 Critical | BS-001 открыта | 1. Выбрать чип «Круг»<br>2. Нажать «Применить» | На SCR-002 только слоты программы «Гончарный круг» |
| **TC-FIL-004** | Мультивыбор программ (ИЛИ внутри группы) | 🔴 Critical | BS-001 открыта | 1. Выбрать «Лепка» и «Круг»<br>2. Нажать «Применить» | Слоты обеих программ отображаются (OR внутри группы) |
| **TC-FIL-005** | Фильтрация по диапазону дат (до месяца) | 🔴 Critical | BS-001 открыта | 1. Задать диапазон дат «С» и «По» (≤ 1 месяц вперёд)<br>2. Нажать «Применить» | На SCR-002 слоты только в выбранном диапазоне |
| **TC-FIL-006** | Быстрые пресеты дат | 🔴 Critical | BS-001 открыта | 1. Выбрать пресет «Сегодня» / «Эта неделя» / «Выходные»<br>2. Нажать «Применить» | Список отфильтрован по выбранному пресету |
| **TC-FIL-007** | Toggle «Только со свободными местами» | 🔴 Critical | BS-001 открыта; есть занятые и свободные слоты | 1. Включить toggle<br>2. Нажать «Применить» | На SCR-002 только слоты с free_seats > 0 |
| **TC-FIL-008** | Комбинирование фильтров (AND между группами) | 🔴 Critical | BS-001 открыта | 1. Задать диапазон дат + программу «Лепка» + toggle свободных мест<br>2. Нажать «Применить» | Слоты удовлетворяют ВСЕМ группам фильтров одновременно |
| **TC-FIL-009** | Empty state после фильтрации | 🔴 Critical | Фильтры заданы так, что слотов нет | 1. Применить фильтры | «Нет слотов по условиям. Попробуйте изменить фильтры.» + кнопка «Сбросить фильтры» |
| **TC-FIL-010** | Сброс фильтров к дефолту | 🔴 Critical | На SCR-002 применены фильтры | 1. Открыть BS-001<br>2. Нажать «Сбросить»<br>3. Нажать «Применить» | Параметры по умолчанию (7 дней, все программы, toggle выкл.); дефолтная выдача |
| **TC-FIL-011** | Закрытие панели без применения | 🔴 Critical | На SCR-002 ранее применены фильтры | 1. Открыть BS-001<br>2. Изменить значения<br>3. Закрыть панель (крестик / клик вне) без «Применить» | Ранее применённые фильтры на SCR-002 не изменились |
| **TC-FIL-012** | Некорректный диапазон дат (По < С) | 🔴 Critical | BS-001 открыта | 1. Задать дату «По» раньше даты «С»<br>2. Нажать «Применить» | Некорректный диапазон не применяется; фильтр не обновляется |

|---|---|---|---|---|---|
| **TC-SLOT-001** | Детали доступного слота | 🔴 Critical | Клиент на SCR-002; слот доступен | 1. Кликнуть по карточке<br>2. Просмотреть SCR-003 | Видны: дата/время, длительность, программа + описание, мастер (фото + имя), места, цена, адрес, статус; кнопка «Записаться» enabled |
| **TC-SLOT-002** | Переход к бронированию с SCR-003 | 🔴 Critical | SCR-003; слот доступен | 1. Нажать «Записаться» | Переход на SCR-004 «Бронирование» |
| **TC-SLOT-003** | Занятый слот: CTA disabled | 🔴 Critical | SCR-003; free_seats = 0 | 1. Открыть детали занятого слота | Блок мест — красный; CTA disabled с текстом «Мест нет» |
| **TC-SLOT-004** | Отменённый мастерской слот | 🔴 Critical | SCR-003; слот отменён мастерской | 1. Открыть детали слота | Бейдж «Отменено мастерской» + причина; кнопка «Записаться» скрыта |
| **TC-SLOT-005** | Запрет повторной записи на отменённый слот | 🔴 Critical | У клиента была бронь на слот, отменённый мастерской | 1. Открыть SCR-003 отменённого слота | Кнопка записи недоступна; повторная запись запрещена (FR-024) |

## Бронирование (BOK)

| ID | Название | Приоритет | Предусловия | Шаги | Ожидаемый результат |
|---|---|---|---|---|---|
| **TC-BOK-001** | Успешное бронирование со своими инструментами | 🔴 Critical | Клиент авторизован; слот доступен (free_seats > 0); клиент на SCR-004 | 1. Убедиться, что выбрано «Свои инструменты и фартук» (по умолчанию)<br>2. Проверить разбивку цены<br>3. Нажать «Записаться» | API создаёт бронь (1 место); открывается BS-002 «Вы записаны»; статус «подтверждена сразу»; итого = цена занятия без доплаты |
| **TC-BOK-002** | Успешное бронирование с прокатом | 🔴 Critical | Слот доступен; прокатный фонд > 0 | 1. Выбрать «Прокат инструментов и фартука»<br>2. Проверить тариф проката и «В наличии: N комплектов» из API<br>3. Нажать «Записаться» | Итого = цена занятия + доплата за прокат; BS-002 показывает «Прокат инструментов» и итоговую цену |
| **TC-BOK-003** | Пересчёт итога при смене выбора инструментов | 🔴 Critical | Клиент на SCR-004 | 1. Выбрать «Свои» — зафиксировать итого<br>2. Переключить на «Прокат»<br>3. Вернуть «Свои» | Итого пересчитывается динамически; при «Прокат» добавляется строка доплаты; блок проката раскрывается с анимацией |
| **TC-BOK-004** | Отображение сводки слота на SCR-004 | 🔴 Critical | Клиент перешёл с SCR-003 | 1. Открыть SCR-004 | Видны: дата, время, программа, мастер (фото + имя); напоминание «Оплата на месте: наличные или перевод на карту» |
| **TC-BOK-005** | Подтверждение записи (BS-002) | 🔴 Critical | Бронь успешно создана | 1. Просмотреть BS-002 | Заголовок «Вы записаны»; сводка: дата/время, программа, мастер, инструменты, итоговая цена; кнопки «Мои записи» и «Готово» |
| **TC-BOK-006** | Переход «Мои записи» из BS-002 | 🔴 Critical | BS-002 открыта | 1. Нажать «Мои записи» | Переход на SCR-005; созданная бронь присутствует в списке «Предстоящие» |
| **TC-BOK-007** | Закрытие BS-002 → возврат к расписанию | 🔴 Critical | BS-002 открыта | 1. Нажать «Готово» или ✕ | Окно закрывается; клиент на SCR-002; свободные места слота уменьшены на 1 |
| **TC-BOK-008** | Отказ API: мест уже нет (race condition) | 🔴 Critical | Слот показывал свободные места, но при бронировании мест нет | 1. Нажать «Записаться» на SCR-004 | Modal: «К сожалению, мест уже нет. Выберите другой слот» + кнопка «К расписанию» → SCR-002; бронь не создана |
| **TC-BOK-009** | CTA disabled для занятого слота | 🔴 Critical | Клиент попал на SCR-004 слота без мест (если доступен прямой переход) | 1. Просмотреть SCR-004 | Кнопка «Записаться» disabled с текстом «Мест нет» |
| **TC-BOK-010** | Ошибка сети при бронировании | 🔴 Critical | Сеть недоступна | 1. Нажать «Записаться» | Toast: «Ошибка соединения. Попробуйте позже»; бронь не создана |
| **TC-BOK-011** | Защита от двойного нажатия «Записаться» | 🔴 Critical | Слот доступен | 1. Нажать «Записаться»<br>2. Повторно нажать во время Loading | CTA в Loading; повторный запрос не отправляется; создаётся только одна бронь |
| **TC-BOK-012** | Одна бронь = одно место | 🔴 Critical | Слот с несколькими свободными местами | 1. Оформить бронь | API резервирует ровно 1 место; в BS-002 нет выбора количества участников |
| **TC-BOK-013** | Тариф и фонд проката из API (не захардкожены) | 🔴 Critical | Выбран «Прокат»; API возвращает tariff и free_count | 1. Просмотреть блок проката на SCR-004 | Отображаются актуальные значения tariff и free_count из API |
| **TC-BOK-014** | Уменьшение прокатного фонда после брони с прокатом | 🔴 Critical | free_count = N; бронь с прокатом создана | 1. Создать бронь с прокатом<br>2. Проверить прокатный фонд | free_count уменьшен на 1 |
| **TC-BOK-015** | Запрос Web Push после первой записи | 🟢 Medium | Это первая успешная запись клиента | 1. Успешно оформить бронь<br>2. Просмотреть BS-002 | После сводки предлагается включить напоминания; системный запрос разрешения на push |
| **TC-BOK-016** | Push не запрашивается повторно | 🟢 Medium | У клиента уже была успешная запись | 1. Оформить вторую бронь<br>2. Просмотреть BS-002 | Запрос push не показывается повторно |
| **TC-BOK-017** | Отказ от push не блокирует запись | 🟢 Medium | Первая запись; BS-002 с предложением push | 1. Отклонить разрешение на push | Бронь остаётся активной; BS-002 работает штатно; запись не блокируется |

| ID | Название | Приоритет | Предусловия | Шаги | Ожидаемый результат |
|---|---|---|---|---|---|
| **TC-CAN-001** | Отмена брони без штрафа (≥ 2 ч до начала) | 🟡 High | Активная бронь; до начала > 2 часов | 1. Открыть SCR-006<br>2. Нажать «Отменить запись»<br>3. В BS-003 проверить блок «Отмена без штрафа»<br>4. Отметить checkbox «Я понимаю условия отмены»<br>5. Нажать «Подтвердить отмену» | Блок: «Отмена без штрафа. До начала более 2 часов.
