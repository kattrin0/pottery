# Гончарка — клиентская часть Vue.js SPA

Демо-клиент для веб-сайта записи в гончарную мастерскую по аналитике из папок `1-elicitation`—`4-design`.

## Что реализовано

- Вход по телефону и SMS-коду: демо-код `1111`.
- Расписание на 7 дней по умолчанию, фильтр по датам, программе и наличию мест.
- Карточка слота с программой, мастером, ценой, адресом, длительностью и статусом.
- Оформление записи на одного человека с выбором своих инструментов или проката.
- Мгновенное подтверждение записи в модальном окне.
- «Мои записи»: предстоящие и прошедшие/отменённые.
- Детали записи, отмена с предпросмотром штрафа из mock API.
- Оценка мастера 1–5 звёзд после завершённого занятия.
- Профиль и настройки Web Push-уведомлений.
- Mock API с хранением данных в `localStorage`, имитирующий клиентский API.

## Запуск

```bash
npm install
npm run dev
```

Откройте адрес, который покажет Vite. Для входа используйте любой телефон и код `1111`.

## Структура

```text
src/
  api/mockApi.js              # имитация API и доменных правил на стороне сервера
  components/                 # общие компоненты: header, badges, modals
  views/                      # экраны SCR-001…SCR-009
  utils/format.js             # форматирование дат, денег, телефона
  App.vue                     # простая маршрутизация SPA без vue-router
```

## Примечания

Это клиентский MVP/прототип. В реальной поставке `src/api/mockApi.js` заменяется адаптером к OpenAPI-контракту клиентского API. Клиент не должен рассчитывать лимиты мест и штрафы самостоятельно — здесь они находятся в mock API только для демонстрации серверных ответов.
