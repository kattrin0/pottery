Аналитика — Гончарная мастерская

Задачи:
- Проанализировать бриф заказчика
- Выявить требования через вопросы
- Составить документацию: BR, FR, NFR, US, UC

Что сделано:
- Изучен бриф, выявлены пробелы
- Составлены 20+ уточняющих вопросов (фильтры, бронь, отмена, оплата, уведомления)
- Созданы 8 файлов с требованиями (BR, FR, NFR, US, UC)
- Определён MVP: расписание, запись, отмена, фильтр по программе

Ключевые решения:
Вопрос	Решение
Фильтры	только по программе
Горизонт	7 дней, до месяца через фильтр
Бронь	одна = одно место, подтверждение сразу
Отмена	2 ч без штрафа, < 2 ч — штраф из API
Оплата	офлайн в MVP
Вход	телефон + SMS-код
Уведомления	Web Push
