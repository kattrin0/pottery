# Требования на дизайн · SCR-006 · Детали записи (десктоп)
ID: SCR-006 · Тип: Экран · Зона: АЗ · Приоритет: Critical
Версия: 0.2 · Дата: 2026-07-05
Источники: [Foundations](00-foundations.md) · [FR-020…024] · [US-012…014] · [UC-005, UC-006]
Сквозные правила – в `00-foundations.md`.

## 1. Назначение и контекст
Полная детализация одной записи клиента. На десктопе – две колонки: слева – информация о брони, справа – действия (отмена, оценка).
Отсюда запускается отмена (через BS-003) и оценка (SCR-008).

## 2. Пользователь и цель
Роль: Клиент, открывший карточку записи.
Цель: проверить детали, при необходимости отменить или оценить мастера.

## 3. Навигация
Входящие: SCR-005 (клик по строке/карточке записи).
Исходящие:
- Кнопка «Отменить» → BS-003 (подтверждение отмены).
- Кнопка «Оценить мастера» → SCR-008 (для прошедших записей без оценки).
- Назад → SCR-005.

## 4. Контент-инвентарь
| Элемент | Источник | Назначение |
|---------|----------|------------|
| Статус брони | booking.status | Бейдж (активна/отменена/поздняя отмена/отменено мастерской) |
| Дата и время | slot.start_at | Крупно |
| Программа | slot → program | Название |
| Мастер | slot → master | Фото + имя |
| Адрес | slot.address | Адрес мастерской |
| Инструменты | booking.use_rental | «Свои» / «Прокат» |
| Цена | slot.price / booking | Итоговая цена |
| Причина отмены мастерской | booking.cancellation_reason | Если статус cancelled_by_workshop |
| Оценка | booking.rating | Если уже оценена |

## 5. Структура и иерархия (десктоп, две колонки)
┌────────────────────────────────────────────────────────────────────┐
│ ‹ Назад Детали записи [статус] │
├────────────────────────────────┬───────────────────────────────────┤
│ Дата и время │ Мастер: │
│ Ср, 15 июля, 18:00—20:00 │ [фото] Анна Козлова │
│ Программа: Лепка для новичков│ Адрес: ул. Гончарная, 12, цех 3│
│ Инструменты: Прокат │ Цена: 1 350 ₽ │
│ Оплата на месте │ [ Отменить запись ] │
│ │ [ Оценить мастера ] │
├────────────────────────────────┴───────────────────────────────────┤
│ (причина отмены мастерской, если есть) │
└────────────────────────────────────────────────────────────────────┘
- Левая колонка – детали.
- Правая – мастер, адрес, цена, кнопки.
- Кнопки – в правой колонке, не фиксированы.

## 6. Компоненты и поведение
- Бейдж статуса: текст + форма (foundations §3.2).
- Блок мастера: аватар 56px, имя, подпись «Мастер».
- Блок инструментов: «Свои инструменты и фартук» / «Прокат инструментов и фартука».
- Напоминание об оплате: «Оплата на месте: наличные или перевод на карту».
- Кнопка «Отменить»: показывается только для активной брони; destructive (красная).
- Кнопка «Оценить мастера»: показывается только для прошедших записей без оценки.
- Если бронь отменена мастерской – показывается причина; кнопка «Отменить» скрыта.

## 7. Состояния экрана
| Состояние | Содержимое |
|-----------|------------|
| Loading | Скелетон блоков |
| Content (активна) | Полные детали + кнопка «Отменить» |
| Content (отменена клиентом) | Детали + бейдж «отменена», без действий |
| Content (отменено мастерской) | Детали + причина + бейдж «отменено мастерской», без действий |
| Content (прошла, не оценена) | Детали + кнопка «Оценить мастера» |
| Content (прошла, оценена) | Детали + текущая оценка (readonly) |
| Error | «Не удалось загрузить детали» + «Повторить» |

## 8. Валидации и микрокопия
| Правило | Текст |
|---------|-------|
| Активна | Бейдж «активна», доступна «Отменить запись» |
| Отменена клиентом | Бейдж «отменена» |
| Поздняя отмена | Бейдж «поздняя отмена» |
| Отменено мастерской | Бейдж «отменено мастерской» + причина |
| Оплата | «Оплата на месте: наличные или перевод на карту» |

## 9. Доступность и адаптивность (десктоп)
- Бейджи статусов – текст + форма, не только цветом.
- Аватар мастера: 56px, круг.
- Кнопка «Отменить»: destructive, тач-зона ≥ 32px (десктоп).
- Адаптив: контейнер max-width 900px на планшете/десктопе; на мобильных – одна колонка.

## 10. Критерии приёмки дизайна
AC-001 — Детали активной записи
  Дано: у клиента есть активная бронь
  Когда: открыт SCR-006
  Тогда: видны дата/время, программа, мастер, адрес, инструменты, цена, статус «активна»
  И доступна кнопка «Отменить запись»

AC-002 — Отменённая мастерской запись
  Дано: бронь отменена мастерской
  Когда: открыт SCR-006
  Тогда: видна причина отмены, кнопка «Отменить» скрыта

AC-003 — Прошедшая запись без оценки
  Дано: бронь в статусе «завершена», оценка не оставлена
  Когда: открыт SCR-006
  Тогда: видна кнопка «Оценить мастера»

AC-004 — Прошедшая запись с оценкой
  Дано: клиент уже оценил мастера
  Когда: открыт SCR-006
  Тогда: показана текущая оценка (readonly звёзды)

## 11. Решения
| # | Решение |
|---|---------|
| 1 | Отмена – через BS-003 (подтверждение со штрафом или без), не на этом экране. |
| 2 | Оценка – через SCR-008, только для прошедших записей без оценки. |
| 3 | Причина отмены мастерской – из API, не захардкожена. |
| 4 | На десктопе – две колонки. |
