# Требования на дизайн · SCR-008 · Оценка мастера (десктоп)
ID: SCR-008 · Тип: Экран / Модальное окно · Зона: АЗ · Приоритет: Should
Версия: 0.2 · Дата: 2026-07-05
Источники: [Foundations](00-foundations.md) · [FR-025] · [US-017] · [UC-007] · [BR-010]
Сквозные правила – в `00-foundations.md`.

## 1. Назначение и контекст
Оценка мастера после занятия. На десктопе – центрированное модальное окно (или отдельная страница) с крупными звёздами.
Доступен только для завершённых броней.

## 2. Пользователь и цель
Роль: Клиент, посетивший занятие.
Цель: быстро оставить оценку мастеру.

## 3. Навигация
Входящие: SCR-006 (кнопка «Оценить мастера» в карточке прошедшей записи).
Исходящие: SCR-006 (после успешной отправки или пропуска).
Назад: возврат на SCR-006.

## 4. Контент-инвентарь
| Элемент | Источник | Назначение |
|---------|----------|------------|
| Дата занятия | slot.start_at | Когда было |
| Программа | slot → program | Какое занятие |
| Мастер | slot → master | Фото + имя |
| Звёзды (1-5) | — | Интерактивный выбор |
| Комментарий | — | Опционально |

## 5. Структура и иерархия (десктоп, модальное окно, ширина 480px)
┌─────────────────────────────────────┐
│ Оценка мастера [✕] │
│ ─────────────────────────────────── │
│ Ср, 15 июля │
│ Лепка для новичков │
│ [фото] │
│ Анна Козлова │
│ Как прошло занятие? │
│ ☆ ☆ ☆ ☆ ☆ │
│ «Хорошо» │
│ Поделитесь впечатлением │
│ [] │
│ [] │
│ [ Отправить оценку ] │
│ Пропустить │
└─────────────────────────────────────┘
- Модалка центрирована.
- Звёзды: 5 интерактивных иконок, 40x40px, gap 12px. При тапе на N-ю звезду – заполняются звёзды 1..N. Подпись меняется: 1 – «Очень плохо», 2 – «Плохо», 3 – «Нормально», 4 – «Хорошо», 5 – «Отлично».
- Поле комментария: textarea, опционально, автовысота (3-6 строк).
- Кнопка «Отправить оценку»: disabled до выбора звезды.
- Кнопка «Пропустить»: text button, возврат без отправки.

## 6. Компоненты и поведение
- Звёзды: тач-зона 44x44px (на десктопе – 32px, но визуально 40px).
- Анимация звёзд: transition 200ms.

## 7. Состояния экрана
| Состояние | Содержимое |
|-----------|------------|
| Content | Форма оценки |
| Оценка уже оставлена | «Вы уже оставили оценку» + текущая оценка (readonly) + «Назад» |
| Бронь не завершена | Редирект на SCR-006 |
| Успех | Toast «Спасибо за оценку!» + возврат на SCR-006 |
| Ошибка | Toast «Не удалось сохранить оценку. Попробуйте позже» |

## 8. Валидации и микрокопия
| Правило | Текст |
|---------|-------|
| Звезда не выбрана | Кнопка «Отправить» disabled |
| Успех | «Спасибо за оценку!» |
| Уже оценено | «Вы уже оставили оценку» |
| Ошибка | «Не удалось сохранить оценку. Попробуйте позже» |

## 9. Доступность и адаптивность (десктоп)
- Звёзды: тач-зона 44x44px (для мыши можно меньше, но оставляем).
- Аватар мастера: 72px круг.
- Textarea: border-radius 12px, padding 12px.
- Адаптив: контейнер max-width 480px на планшете/десктопе; на мобильных – 90% ширины.

## 10. Критерии приёмки дизайна
AC-001 — Выбор оценки
  Дано: открыт SCR-008
  Когда: клиент тапает на 4-ю звезду
  Тогда: заполняются 4 звезды, подпись «Хорошо»

AC-002 — Отправка оценки
  Дано: звезда выбрана
  Когда: нажата «Отправить оценку»
  Тогда: toast «Спасибо за оценку!», возврат на SCR-006

AC-003 — Пропуск
  Дано: открыт SCR-008
  Когда: нажата «Пропустить»
  Тогда: возврат на SCR-006 без отправки

AC-004 — Оценка уже оставлена
  Дано: клиент уже оценил мастера
  Когда: открыт SCR-008
  Тогда: «Вы уже оставили оценку» + текущая оценка (readonly)

## 11. Решения
