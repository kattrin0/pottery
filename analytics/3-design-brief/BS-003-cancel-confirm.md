# Требования на дизайн · BS-003 · Подтверждение отмены (десктоп)
ID: BS-003 · Тип: Модальное окно (деструктивное) · Зона: АЗ · Приоритет: Critical
Версия: 0.2 · Дата: 2026-07-05
Источники: [Foundations](00-foundations.md) · [FR-020…022] · [US-012, US-013] · [UC-005] · [BR-008] · [NFR-010]
Сквозные правила заданы в `00-foundations.md` и здесь не дублируются.

## 1. Назначение и контекст
Критическое действие – отмена брони. Используется **модальное окно** с явным подтверждением.
На десктопе – центрировано, затемнение фона, нельзя закрыть кликом вне окна.
Реализует принцип «осознанного действия» (foundations §2, P6).

## 2. Пользователь и цель
Роль: Клиент с активной бронью, решивший отменить запись.
Цель пользователя: осознанно подтвердить или отменить действие по отмене.
Цель продукта: предотвратить случайную отмену, показать последствия (в т.ч. штраф).

## 3. Навигация
Входящие: SCR-006 → кнопка «Отменить запись».
Исходящие:
- «Подтвердить отмену» → API обрабатывает отмену → toast «Бронь отменена» → возврат на SCR-005.
- «Оставить бронь» → возврат на SCR-006 без изменений.

Особенность BS-003: клик по бэкдропу НЕ закрывает окно (деструктивное действие требует явного выбора).
Закрытие только кнопками (крестик отсутствует).

## 4. Контент-инвентарь
| # | Элемент | Источник | Назначение |
|---|---------|----------|------------|
| 1 | Сводка брони | booking + slot | Дата, программа, мастер, цена |
| 2 | Время до начала | расчёт | «1 ч 30 мин» |
| 3 | % штрафа | API | Из API (NFR-010) |
| 4 | Сумма штрафа | API | Расчётная сумма |
| 5 | Checkbox подтверждения | — | «Я понимаю условия отмены» |
| 6 | Кнопка «Подтвердить отмену» | — | Destructive (красная) |
| 7 | Кнопка «Оставить бронь» | — | Secondary |

- Блок последствий выделен цветом (зелёный/оранжевый) и формой.
- Checkbox обязателен для активации кнопки «Подтвердить отмену».
- Кнопка «Подтвердить отмену» – красная, disabled до checkbox.
- Кнопка «Оставить бронь» – серая, всегда активна.

## 6. Компоненты и поведение
- Блок последствий: border-radius 12px, padding 20px.
- Checkbox: тач-зона на весь ряд (на десктопе – 32px, на мобильных – 44px).
- Кнопка «Подтвердить отмену»: высота 40px (десктоп), border-radius 8px.
- Loading при ожидании ответа API.
- Успех: toast «Бронь отменена» + возврат на SCR-005.

## 7. Состояния экрана
| Состояние | Содержимое |
|-----------|------------|
| Loading | Спиннер при загрузке деталей и правил отмены |
| Content (без штрафа) | Вариант А |
| Content (со штрафом) | Вариант Б |
| Бронь уже отменена | «Эта бронь уже отменена» + «К списку броней» |
| Слот отменён мастерской | «Занятие отменено мастерской. Причина: …» + «К списку броней» |
| Успех | Toast «Бронь отменена» + возврат на SCR-005 |
| Ошибка сети | Toast «Не удалось отменить бронь. Попробуйте позже» |

## 8. Валидации и микрокопия
| Правило | Текст |
|---------|-------|
| Без штрафа | «Отмена без штрафа. До начала более 2 часов. Место освободится.» |
| Со штрафом | «Поздняя отмена. До начала менее 2 часов. Штраф: N% от стоимости. Сумма: X ₽» |
| Checkbox не отмечен | Кнопка «Подтвердить отмену» disabled |
| Успех | Toast «Бронь отменена» |
| Ошибка сети | «Не удалось отменить бронь. Попробуйте позже» |

## 9. Доступность и адаптивность (десктоп)
- Блок последствий: border-radius 16px, padding 20px.
- Кнопка destructive: фон #D32F2F, высота 40px, border-radius 8px.
- Checkbox: тач-зона 32px (на десктопе), весь ряд.
- Адаптив: контейнер max-width 520px на планшете/десктопе; на мобильных – 90% ширины.

## 10. Критерии приёмки дизайна
AC-001 — Отмена без штрафа
  Дано: до начала более 2 часов
  Когда: открыта BS-003
  Тогда: показан блок «Отмена без штрафа» (зелёный фон)

AC-002 — Поздняя отмена
  Дано: до начала менее 2 часов
  Когда: открыта BS-003
  Тогда: показан блок «Поздняя отмена» с % и суммой штрафа из API

AC-003 — Checkbox обязателен
  Дано: checkbox не отмечен
  Когда: —
  Тогда: кнопка «Подтвердить отмену» disabled

AC-004 — Успешная отмена
  Дано: checkbox отмечен, нажата «Подтвердить отмену»
  Когда: API вернул успех
  Тогда: toast «Бронь отменена», возврат на SCR-005

AC-005 — Бронь уже отменена
  Дано: статус брони — отменена
  Когда: открыта BS-003
  Тогда: «Эта бронь уже отменена» + кнопка «К списку броней»

AC-006 — Закрытие только явным действием
  Дано: открыта BS-003
  Когда: клиент пытается закрыть кликом вне окна или Esc
  Тогда: окно не закрывается; доступны только кнопки «Подтвердить отмену» / «Оставить бронь»

## 11. Решения
| # | Решение |
|---|---------|
| 1 | % штрафа и порог в часах – из API, не захардкожены. |
| 2 | Checkbox подтверждения обязателен – защита от случайного действия. |
| 3 | Кнопка destructive – красная, визуально отлична от вторичной. |
| 4 | Клик по бэкдропу и Esc – отключены (деструктивное действие). |
| 5 | На десктопе – модальное окно вместо шторки. |
