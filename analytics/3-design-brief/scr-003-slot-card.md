# Требования на дизайн · SCR-003 · Карточка слота (десктоп)
ID: SCR-003 · Тип: Экран · Зона: АЗ · Приоритет: High
Версия: 0.2 · Дата: 2026-07-05
Источники: [Foundations](00-foundations.md) · [FR-008, FR-009, FR-012] · [US-005, US-006] · [UC-002]
Сквозные правила – в `00-foundations.md`.

## 1. Назначение и контекст
Детальный просмотр слота. На десктопе – отдельная страница (или модальное окно)
с двухколоночной структурой: слева – информация, справа – блок бронирования.
Может быть реализован как отдельный экран или как модальное окно – решение за дизайнером.

## 2. Пользователь и цель
Роль: Клиент, выбравший слот в расписании.
Цель: оценить детали занятия и принять решение о записи.

## 3. Навигация
Входящие: SCR-002 (клик по карточке).
Исходящие: SCR-004 (кнопка «Записаться»).
Назад: возврат на SCR-002.

## 4. Контент-инвентарь
| Элемент | Источник | Назначение |
|---------|----------|------------|
| Дата и время | slot.start_at | Крупно, основной ориентир |
| Длительность | slot.duration_minutes | «2 часа» |
| Программа | slot → program | Название + описание |
| Мастер | slot → master | Фото + имя |
| Места | slot.free_seats / total_seats | «3 из 6 мест» |
| Цена | slot.price | Крупно |
| Адрес | slot.address | С иконкой локации |
| Статус | slot.status | Бейдж |

## 5. Структура и иерархия (десктоп, две колонки)
┌────────────────────────────────────────────────────────────────────┐
│ ‹ Назад Занятие [статус] │
├────────────────────────────────┬───────────────────────────────────┤
│ Среда, 15 июля │ Мастер: │
│ 18:00 — 20:00 · 2 часа │ [фото] Анна Козлова │
│ Лепка для новичков │ 👥 3 из 6 мест свободно │
│ Описание: ... │ 📍 ул. Гончарная, 12, цех 3 │
│ │ 💰 1 200 ₽ │
│ │ [ Записаться ] │
├────────────────────────────────┴───────────────────────────────────┤
│ (дополнительная информация, отзывы и т.п. – опционально) │
└────────────────────────────────────────────────────────────────────┘

- Левая колонка – детали программы и время.
- Правая колонка – мастер, места, цена, кнопка.
- Кнопка фиксирована не внизу, а в правой колонке.

## 6. Компоненты и поведение
- Блок мастера: аватар 56px, имя, подпись «Мастер».
- Описание программы: 2-4 строки, при необходимости – раскрытие по клику.
- Блок мест: цвет по статусу (зелёный/жёлтый/красный), текст + иконка.
- Кнопка «Записаться» – в правой колонке, не фиксирована.
- Кнопка disabled при статусе «Мест нет» или «Отменено мастерской».

## 7. Состояния экрана
| Состояние | Содержимое |
|-----------|------------|
| Loading | Скелетон блоков |
| Content | Полная детализация |
| Мест нет | CTA disabled «Мест нет», блок мест – красный |
| Отменено мастерской | Бейдж «Отменено», причина, CTA скрыт |

## 8. Валидации и микрокопия
| Правило | Текст |
|---------|-------|
| Мест нет | Бейдж «Мест нет», CTA «Мест нет» |
| Отменено мастерской | Бейдж «Отменено мастерской» + причина из API |

## 9. Доступность и адаптивность (десктоп)
- Аватар мастера: 56px, круг, border.
- Кнопка CTA: высота 40px, border-radius 8px.
- Адаптив: на планшете/десктопе – контейнер max-width 900px по центру; на мобильных – одна колонка.

## 10. Критерии приёмки дизайна
AC-001 — Детали слота
  Дано: клиент выбрал слот
  Когда: открыт SCR-003
  Тогда: видны дата/время, программа, мастер, места, цена, адрес, описание

AC-002 — Переход к бронированию
  Дано: слот доступен
  Когда: нажата «Записаться»
  Тогда: открывается SCR-004

AC-003 — Слот занят
  Дано: мест нет
  Когда: открыт SCR-003
  Тогда: CTA disabled «Мест нет»

## 11. Решения

| 3 | На десктопе – две колонки. |
