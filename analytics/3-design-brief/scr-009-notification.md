# Требования на дизайн · SCR-009 · Настройки уведомлений (десктоп)
ID: SCR-009 · Тип: Экран · Зона: АЗ · Приоритет: Should
Версия: 0.2 · Дата: 2026-07-05
Источники: [Foundations](00-foundations.md) · [FR-026…028] · [US-015, US-016] · [UC-008] · [BR-011] · [NFR-012]
Сквозные правила – в `00-foundations.md`.

## 1. Назначение и контекст
Управление подпиской клиента на Web Push-уведомления. На десктопе – отдельная страница (или модалка) с переключателями.
Включает/выключает напоминания о записи и уведомления об отмене мастерской.

## 2. Пользователь и цель
Роль: Клиент, желающий настроить уведомления.
Цель: включить или отключить нужные типы уведомлений.

## 3. Навигация
Входящие: SCR-007 (профиль → настройки).
Исходящие: Назад → SCR-007.

- Карточка центрирована, ширина ~520px.
- Статус подписки: badge «Включены» (зелёный) / «Выключены» (серый) / «Заблокированы» (красный).
- Toggle: switch 52x28px, рычажок 24x24px. Строка toggle – min-height 64px (тач-зона).
- Информационный блок: фон #F5F5F5, border-radius 12px.

## 6. Компоненты и поведение
- Toggle'ы сохраняют настройки мгновенно (optimistic update) с rollback при ошибке.
- Блок «Заблокировано браузером»: фон #FFF3E0, инструкция «Разрешите уведомления в настройках браузера».

## 7. Состояния экрана
| Состояние | Содержимое |
|-----------|------------|
| Loading | Спиннер при загрузке настроек |
| Content (подписан) | Toggle'ы активны, badge «Включены» |
| Content (не подписан) | Кнопка «Включить уведомления», toggle'ы disabled |
| Браузер не поддерживает | «Ваш браузер не поддерживает push-уведомления» |
| Заблокировано браузером | Блок с инструкцией |
| Успешное изменение | Мгновенное сохранение (optimistic update) |
| Ошибка сохранения | Toast + rollback toggle |

## 8. Валидации и микрокопия
| Правило | Текст |
|---------|-------|
| Включить | «Включить уведомления» |
| Отключить | «Отключить» |
| Напоминания | «Напоминания о записи. За день и за час до занятия» |
| Отмена | «Уведомления об отмене. Мгновенное уведомление при отмене мастерской» |

## 9. Доступность и адаптивность (десктоп)
- Toggle: тач-зона 32px (десктоп).
- Строка toggle: min-height 64px.
- Информационный блок: padding 16px.
- Адаптив: контейнер max-width 520px на планшете/десктопе; на мобильных – 90% ширины.

## 10. Критерии приёмки дизайна
AC-001 — Включение уведомлений
  Дано: клиент не подписан
  Когда: нажата «Включить уведомления»
  Тогда: браузер запрашивает разрешение; при согласии – toggle'ы активны, badge «Включены»

AC-002 — Переключение типа
  Дано: клиент подписан
  Когда: переключён toggle «Напоминания о записи»
  Тогда: настройка сохраняется, toggle меняет состояние

AC-003 — Браузер не поддерживает
  Дано: браузер без Web Push
  Когда: открыт SCR-009
  Тогда: «Ваш браузер не поддерживает push-уведомления»

AC-004 — Заблокировано браузером
  Дано: разрешение запрещено
  Когда: открыт SCR-009
  Тогда: блок с инструкцией «Разрешите уведомления в настройках браузера»
