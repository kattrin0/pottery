# Требования на дизайн · SCR-004 · Оформление записи (десктоп)
ID: SCR-004 · Тип: Экран · Зона: АЗ · Приоритет: Critical
Версия: 0.2 · Дата: 2026-07-05
Источники: [Foundations](00-foundations.md) · [FR-013…019] · [US-008…011] · [UC-004] · [data-model] · [api-sequence]
Сквозные правила – в `00-foundations.md`.

## 1. Назначение и контекст
Форма оформления брони. На десктопе – две колонки: слева – выбор опций, справа – итог и кнопка.
Одна бронь = одно место (FR-013). Выбор инструментов (FR-014). Цена и доплата – до записи (FR-015).

## 2. Пользователь и цель
Роль: Клиент, решивший записаться.
Цель: оформить бронь и получить подтверждение.

## 3. Навигация
Входящие: SCR-003 (кнопка «Записаться»).
Исходящие: BS-002 (успешное бронирование).
Остается на SCR-004: при ошибке API (нет мест).
Назад: возврат на SCR-003 / SCR-002.

## 4. Контент-инвентарь
| Элемент | Источник | Назначение |
|---------|----------|------------|
| Сводка слота | slot | Дата, время, программа, мастер |
| Radio «Свои инструменты» | — | По умолчанию, без доплаты |
| Radio «Прокат» | — | Добавляет доплату |
| Тариф проката | rental.tariff | Из API (FR-016) |
| Свободный фонд проката | rental.free_count | Из API (FR-016) |
| Цена занятия | slot.price | Из API |
| Итого | расчёт | Цена + доплата |

- Левая колонка – краткая сводка слота.
- Правая – выбор опций, расчёт, кнопка.
- Кнопка «Записаться» – в правой колонке, не фиксирована.

## 6. Компоненты и поведение
- Radio-группа: выбор «Свои» / «Прокат». При выборе «Прокат» раскрывается блок с тарифом
  и свободным фондом (анимация slide-down, 200ms).
- Разбивка стоимости: пересчитывается при смене выбора.
- Кнопка «Записаться»: enabled при доступном слоте; loading при ожидании ответа API.
- Напоминание об оплате: «Оплата на месте: наличные или перевод на карту» (foundations §6).
- При ошибке «мест нет» – модальное окно с предложением выбрать другой слот.

## 7. Состояния экрана
| Состояние | Содержимое |
|-----------|------------|
| Loading | Краткий спиннер при загрузке деталей |
| Content | Форма с выбором и разбивкой |
| Ошибка «Мест нет» (отказ API) | Modal: «К сожалению, мест уже нет. Выберите другой слот» + кнопка «К расписанию» → SCR-002 |
| Ошибка сети | Toast: «Ошибка соединения. Попробуйте позже» |

## 8. Валидации и микрокопия
| Правило | Текст |
|---------|-------|
| Слот недоступен | Кнопка disabled «Мест нет» |
| Отказ API (нет мест) | «К сожалению, мест уже нет. Выберите другой слот» |
| Ошибка сети | «Ошибка соединения. Попробуйте позже» |
| Оплата | «Оплата на месте: наличные или перевод на карту» |

## 9. Доступность и адаптивность (десктоп)
- Radio-кнопки: область нажатия на весь ряд (не только круг), тач-зона ≥ 32px (десктоп).
- Кнопка: высота 40px.
- Адаптив: контейнер max-width 900px на планшете/десктопе; на мобильных – одна колонка.

## 10. Критерии приёмки дизайна
AC-001 — Сводка слота
  Дано: клиент перешёл с SCR-003
  Когда: открыт SCR-004
  Тогда: видны дата, время, программа, мастер

AC-002 — Выбор проката
  Дано: открыт SCR-004
  Когда: выбран «Прокат»
  Тогда: показан тариф и свободный фонд, итого пересчитано

AC-003 — Успешная запись
  Дано: слот доступен
  Когда: нажата «Записаться»
  Тогда: открывается BS-002

AC-004 — Отказ API (нет мест)
  Дано: мест уже нет
  Когда: нажата «Записаться»
  Тогда: показан modal «Мест уже нет» + кнопка «К расписанию»

## 11. Решения
| # | Решение |
|---|---------|
| 1 | Одна бронь = одно место (FR-013). |
