# Требования на дизайн · SCR-001 · Вход (десктоп)
ID: SCR-001 · Тип: Экран · Зона: НЗ · Приоритет: Critical
Версия: 0.2 · Дата: 2026-07-05
Источники: [Foundations](00-foundations.md) · [FR-001, FR-002] · [US-001] · [UC-001] · [NFR-003]
Сквозные правила описаны в `00-foundations.md` и здесь не дублируются.

## 1. Назначение и контекст
Страница входа. На десктопе – центрированная карточка с формой, без нижнего фиксированного CTA.
Максимальная ширина формы – 400px, расположена по центру экрана.
Реализует принцип минимального порога входа (foundations §2, P3). Поток – двухшаговый
(телефон → код).

## 2. Пользователь и цель
Кто: клиент гончарной мастерской.
Цель пользователя: быстро войти и попасть в расписание.

## 3. Навигация
Входящие:
- Открытие сайта / переход по ссылке – пользователь не авторизован.
- Выход из профиля (SCR-007) – возврат в НЗ.
Исходящие:
- Успешное подтверждение → SCR-002 «Расписание» (стартовая вкладка АЗ).
- Если сессия уже есть – экран не показывается, сразу SCR-002.

## 5. Структура и иерархия (десктоп)
Каркас – foundations §4.1. Хедер отсутствует (или минимальный). Форма по центру.

Шаг 1 — Телефон:
┌─────────────────────────────────────────────────────────┐
│ (логотип) │
│ Вход │
│ Введите номер телефона │
│ ┌──────────────────────────────────────────────────┐ │
│ │ Телефон [+7 ___ _--__] │ │
│ └──────────────────────────────────────────────────┘ │
│ Без пароля — вход по номеру │
│ [ Получить код ] │
└─────────────────────────────────────────────────────────┘
Шаг 2 — Код из SMS:
┌─────────────────────────────────────────────────────────┐
│ ‹ Назад │
│ Мы отправили код на +7 999 123-45-67 │
│ Код из SMS │
│ [] [] [] [] │
│ Отправить код повторно (0:30) │
│ Изменить номер │
│ [ Войти ] │
└─────────────────────────────────────────────────────────┘

- Нет фиксированного нижнего CTA – кнопка под полем.
- На десктопе клавиатура не перекрывает поля.

## 6. Компоненты и поведение (без изменений, но без мобильных нюансов)
Поле «Телефон»: маска национального формата, числовая клавиатура, автофокус. Disabled CTA
пока номер не заполнен.
Поле «Код»: 4 ячейки, автопереход, автоотправка по заполнении последней (или по кнопке «Войти»).
Таймер повторной отправки: ссылка неактивна с обратным отсчётом; по истечении – активна.
Кнопка «Войти»: disabled до полного ввода кода; loading при проверке; защита от двойного тапа.
Назад: возврат к шагу 1, номер сохраняется.

## 7. Состояния экрана
| Состояние | Содержимое / Поведение |
|-----------|------------------------|
| Content (шаг 1) | Поле телефона + CTA «Получить код» |
| Content (шаг 2) | Поле кода + таймер + CTA «Войти» |
| Loading (отправка/проверка) | CTA в состоянии Loading, поля заблокированы |
| Валидация поля | Подсветка невалидного поля + текст ошибки под полем |
| Неверный код | Сообщение + возможность ввести заново, номер из шага 1 не теряется |
| Error (сеть) | Заглушка + кнопка «Повторить» |

## 8. Валидации и микрокопия
| Правило | Текст |
|---------|-------|
| Телефон не заполнен | «Введите номер телефона» |
| Неполный/неверный формат | «Похоже, номер введён не полностью» |
| Над полем кода | «Мы отправили код на <номер>» |
| Неверный код | «Неверный код. Проверьте и введите ещё раз» |
| Таймер повтора | «Отправить код повторно (0:30)» |
| Ошибка сети | «Не удалось войти. Попробуйте ещё раз» |
| Превышены попытки | «Слишком много попыток. Попробуйте позже» |

## 9. Доступность и адаптивность (десктоп)
- Тач-зоны по foundations §3.1 (для мобильных – 44px, для десктопа – 32px).
- Числовая клавиатура для телефона и кода.
- Автофокус на активном поле каждого шага.
- Лейблы и доступные имена у всех полей.
- Поддержка системного увеличения шрифта.
- Адаптив: на планшете/десктопе форма центрирована, max-width 400px; на мобильных – 90% ширины.

## 10. Критерии приёмки дизайна
AC-001 — Шаг 1: минимальный ввод
  Дано: пользователь не авторизован
  Когда: открылся SCR-001
  Тогда: видно только поле «Телефон» и CTA «Получить код»; поля пароля отсутствуют

AC-002 — CTA активируется при валидном телефоне
  Дано: поле «Телефон» заполнено корректно
  Когда: —
  Тогда: кнопка «Получить код» переходит из disabled в enabled

AC-003 — Отправка кода
  Дано: введён валидный телефон
  Когда: нажата «Получить код»
  Тогда: открывается шаг 2 с полем кода и таймером

AC-004 — Успешный вход
  Дано: введён верный код
  Когда: нажата «Войти»
  Тогда: устанавливается сессия, открывается SCR-002

AC-005 — Неверный код
  Дано: введён неверный код
  Когда: нажата «Войти»
  Тогда: показывается «Неверный код…», поле очищается, фокус возвращается

AC-006 — Таймер и повторная отправка
  Дано: код только что отправлен
  Когда: идёт обратный отсчёт
  Тогда: ссылка «Отправить код повторно» неактивна, затем активируется

AC-007 — Защита от двойной отправки
  Дано: пользователь нажал CTA
  Когда: идёт ожидание ответа
  Тогда: повторная отправка не выполняется, CTA в Loading

## 11. Решения
| # | Решение |
|---|---------|
| 1 | Двухшаговый поток: телефон → код. Шага «Имя» нет. |
| 2 | Пароль отсутствует принципиально (NFR-003). |
| 3 | Запрос разрешения на Web Push – не здесь, а после первой успешной записи (BS-002). |
| 4 | Длина кода и таймер – параметры конфигурации; в макете 4 цифры и 30 секунд. |
| 5 | На десктопе – центрированная карточка, без нижнего CTA. |
