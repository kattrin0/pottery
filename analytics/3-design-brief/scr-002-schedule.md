# Требования на дизайн · SCR-002 · Расписание (десктоп)
ID: SCR-002 · Тип: Экран · Зона: АЗ · Приоритет: Critical
Версия: 0.2 · Дата: 2026-07-05
Источники: [Foundations](00-foundations.md) · [FR-003…012] · [US-002…007] · [UC-002, UC-003] · [data-model]
Сквозные правила – в `00-foundations.md`, здесь только ссылки и специфика.

## 1. Назначение и контекст
Главный экран после входа. На десктопе отображается в виде сетки карточек (3–4 колонки)
с возможностью фильтрации через боковую панель или выпадающий блок.
Навигация – горизонтальные вкладки в хедере.

## 2. Пользователь и цель
Роль: Клиент.
Цель: быстро найти подходящее занятие и перейти к бронированию.

## 3. Навигация
Входящие:
- SCR-001 (вход) — после успешной авторизации.
- BS-002 (Подтверждение записи) — кнопка «Готово».
- SCR-005 (Мои записи) — empty state «Записаться на занятие».
- Вкладка «Расписание» в хедере (с любой страницы).
Исходящие:
- Клик по карточке → SCR-003.
- Кнопка «Фильтры» → открытие панели фильтров (BS-001).
- Вкладка «Мои записи» → SCR-005.
- Иконка профиля → SCR-007.

Каркас: хедер с вкладками, основная область с контентом. Таб-бар отсутствует.

## 4. Контент-инвентарь
### 4.1 Карточка слота
| Поле | Источник | Назначение |
|------|----------|------------|
| start_at | slot | Дата и время – крупно, основной ориентир |
| program.name | slot → program | Название программы |
| master.name + фото | slot → master | Кто ведёт (FR-012) |
| free_seats / total_seats | slot | Свободные места |
| price | slot | Цена |
| duration_minutes | slot | Длительность |
| description | slot | Краткое описание |
| address | slot | Адрес мастерской |
| status | slot | «Доступно» / «Мест нет» / «Мало мест» / «Отменено» |

### 4.2 Панель фильтров
- Горизонтальная лента дат (7 дней по умолчанию, FR-004).
- Кнопка «Фильтры» → BS-001.
- Индикатор активных фильтров (если применены).

## 6. Компоненты и поведение (обновлено)
- Карточка – кликабельна вся область (тач-зона ≥ 32px на десктопе).
- Ховер-эффекты на карточках (тень, масштаб 1.02).
- Pull-to-refresh не нужен – кнопка «Обновить» или автоматическое обновление.
- Бейдж статуса: текст + форма, не только цвет.

## 7. Состояния экрана
| Состояние | Содержимое / Поведение |
|-----------|------------------------|
| Loading | Скелетоны карточек (3-4 штуки), лента дат и фильтры загружены |
| Content | Список карточек, отсортированных по дате/времени |
| Empty (нет слотов) | «Пока нет доступных занятий» + кнопка «Сбросить фильтры» (если фильтры активны) |
| Empty (после фильтров) | «Нет слотов по условиям. Попробуйте изменить фильтры.» + действие |
| Error | «Не удалось загрузить расписание» + кнопка «Повторить» |

## 8. Валидации и микрокопия
| Правило | Текст |
|---------|-------|
| Нет слотов | «Пока нет доступных занятий» |
| Нет слотов по фильтрам | «Нет слотов по условиям. Попробуйте изменить фильтры.» |
| Ошибка сети | «Не удалось загрузить расписание. Попробуйте позже» |
| Слот занят | Бейдж «Мест нет» (FR-009, US-006) |
| Слот отменён | Бейдж «Отменено мастерской» + причина |

## 9. Доступность и адаптивность (десктоп)
- Крупные карточки с большой тач-зоной.
- Бейджи статусов – текст + форма, читаемы на солнце и при дальтонизме.
- Даты/время – понятный формат (день недели + дата + время).
- Лента дат и фильтры имеют доступные имена для screen reader.
- Адаптив: на планшете – 2 колонки, на десктопе – 3-4 колонки, max-width 1400px.
- На мобильных – 1 колонка.

## 10. Критерии приёмки дизайна
AC-001 — Загрузка расписания
  Дано: клиент вошёл на сайт
  Когда: открывается SCR-002
  Тогда: показываются слоты на ближайшие 7 дней, отсортированные по дате/времени

AC-002 — Карточка слота содержит все поля
  Дано: слот загружен
  Когда: клиент видит карточку
  Тогда: видны время, программа, мастер с фото, места, цена, длительность, адрес, статус

AC-003 — Занятые слоты отображаются
  Дано: слот полностью занят
  Когда: клиент видит карточку
  Тогда: показан бейдж «Мест нет», карточка не скрывается (FR-009)

AC-004 — Переход к деталям
  Дано: показана карточка
  Когда: клиент тапает по карточке
  Тогда: открывается SCR-003

AC-005 — Открытие фильтров
  Дано: клиент на SCR-002
  Когда: нажата «Фильтры»
  Тогда: открывается BS-001 (панель/блок)

AC-006 — Empty state
  Дано: слотов нет
  Когда: загружен SCR-002
  Тогда: показана заглушка «Пока нет доступных занятий»

AC-007 — Обновление
  Дано: экран в Content
  Когда: нажата кнопка «Обновить» (или автоматически)
  Тогда: список перезапрашивается

## 11. Решения
| # | Решение |
|---|---------|
| 1 | По умолчанию – 7 дней (FR-004, R-027); фильтр дат – до месяца (FR-005). |
| 2 | Фильтр по программе – в BS-001 (FR-006). |
| 3 | Занятые слоты показываются с бейджем «Мест нет» (FR-009), не скрываются. |
| 4 | Лист ожидания – нет (BR-012). |
| 5 | На десктопе – многоколоночная сетка вместо списка. |
| 6 | Фильтры – в панели или выпадающем блоке, а не в шторке. |
| 7 | Навигация – в хедере, а не в нижнем таб-баре. |
