# Требования на дизайн · BS-001 · Фильтры (десктоп-версия)
ID: BS-001 · Тип: Панель / выпадающий блок · Зона: АЗ · Приоритет: High
Статус: Черновик · Версия: 0.2 · Дата: 2026-07-05
Источники: [Foundations](00-foundations.md) · [FR-005, FR-006] · [UC-003]
Сквозные правила заданы в `00-foundations.md` и здесь не дублируются.

## 1. Назначение и контекст
Фильтры позволяют клиенту уточнить список слотов. На десктопе они расположены в виде
**боковой панели** (слева) или **выпадающего блока** над списком (выбор за дизайнером).
Шторка (bottom sheet) не используется – на больших экранах это неудобно.

## 2. Пользователь и цель
Роль: Клиент.
Цель: отфильтровать расписание по дате, программе, наличию мест.

## 3. Навигация
Входящие:
- Клик по кнопке «Фильтры» на SCR-002 → открывается панель/блок.
Исходящие:
- «Применить» → панель закрывается, список обновляется.
- «Сбросить» → сброс параметров.
- Закрытие (клик вне панели или кнопка «Закрыть») → закрытие без применения.

Свойства панели: фиксирована слева (ширина ~320 px) или раскрывается над списком.
Кнопка «Применить» – внизу панели, не фиксирована, но видна без скролла.

## 4. Контент-инвентарь / Параметры фильтров
| # | Параметр | Поле данных | Тип значения | Поведение |
|---|----------|-------------|--------------|-----------|
| 1 | Дата / период старта | start_at | Быстрый пресет или произвольный диапазон | Пресеты «Сегодня» / «Эта неделя» / «Выходные» + произвольный диапазон; по умолчанию – ближайшие 7 дней |
| 2 | Программа занятия | program_id | Множественный выбор из «Лепка для новичков» / «Гончарный круг» | Чип-лист с мультивыбором; по умолчанию – не выбрано |
| 3 | Только со свободными местами | free_seats > 0 | Переключатель (вкл/выкл) | По умолчанию – выкл |

Числовые лимиты не зашиваются.

## 6. Компоненты и поведение (адаптированы под десктоп)
- Чипы – размер 32–36 px, с ховер-эффектами.
- Поля дат – текстовые с календарём (по клику).
- Toggle – стандартный switch или чекбокс.
- Кнопка «Применить» – ширина 100% панели, высота 40px.

## 7. Состояния экрана
| Состояние | Содержимое / Поведение |
|-----------|------------------------|
| Фильтры по умолчанию | Дата – без пресета (дефолт API – 7 дней); программа – не выбрано; «только со свободными местами» – выкл. «Сбросить» неактивно. |
| Выбраны фильтры | Контролы отражают выбор; «Сбросить» активно; «Применить» подтверждает выбор. |
| Пустой результат после применения | Обрабатывается на SCR-002 как empty state, не внутри панели. |

## 8. Валидации и микрокопия
| Правило | Поведение / текст |
|---------|-------------------|
| Корректность диапазона дат | Должно выполняться «от ≤ до». Некорректный диапазон не применяется. |
| Пустой результат после применения (на SCR-002) | «Нет слотов по условиям. Попробуйте изменить фильтры.» |
| Тон | Простой, без вины и давления (foundations §6). |

## 9. Доступность и адаптивность (десктоп)
- Крупные контролы: чипы, toggle, поля дат – ≥ 32px.
- Выбор дат – с клавиатуры.
- Состояния выбора не передаются только цветом.
- Все контролы имеют доступные имена.

## 10. Критерии приёмки дизайна
AC-001 — Открытие панели
  Дано: клиент на SCR-002
  Когда: нажата «Фильтры»
  Тогда: открывается панель фильтров (не шторка) с элементами управления

AC-002 — Комбинирование групп по «И», значений в группе по «ИЛИ»
  Дано: открыта панель BS-001
  Когда: клиент задаёт диапазон дат, отмечает программы «Лепка» и «Круг»
  И нажимает «Применить»
  Тогда: на SCR-002 остаются слоты, удовлетворяющие ВСЕМ группам (AND), где внутри группы достаточно совпадения с любым из выбранных значений (OR)

AC-003 — Применение возвращает на список с индикатором
  Дано: выбран хотя бы один фильтр, отличный от дефолта
  Когда: нажата «Применить»
  Тогда: панель закрывается, возврат на SCR-002, виден индикатор активных фильтров

AC-004 — Сброс возвращает к дефолтной выдаче
  Дано: заданы какие-либо фильтры
  Когда: нажата «Сбросить» и затем «Применить»
  Тогда: все параметры возвращаются к значениям по умолчанию, SCR-002 показывает дефолтную выдачу

AC-005 — Закрытие без применения сохраняет прежние фильтры
  Дано: на SCR-002 ранее были применены фильтры
  Когда: клиент открывает панель, меняет значения и закрывает её (крестик или клик вне)
  Тогда: ранее применённые фильтры на SCR-002 не изменяются

AC-006 — Корректность диапазона дат
  Дано: открыта группа «Дата старта»
  Когда: клиент пытается задать дату «По» раньше даты «С»
  Тогда: некорректный диапазон не применяется

AC-007 — Пустой результат после применения
  Дано: клиент применил фильтры, под которые нет ни одного слота
  Когда: происходит возврат на SCR-002
  Тогда: показывается empty state «Нет слотов по условиям. Попробуйте изменить фильтры.»

## 11. Решения
| # | Решение |
|---|---------|
| 1 | Дата: быстрые пресеты + произвольный диапазон (§6.1). |
| 2 | Программа — множественный выбор (чипы): можно выбрать обе; ИЛИ внутри группы. |
| 3 | Живой счётчик результатов в панели – не делаем. Результат виден на SCR-002 после «Применить». |
| 4 | На десктопе – панель/блок, а не шторка. |
