# Требования на дизайн · SCR-007 · Профиль (десктоп)
ID: SCR-007 · Тип: Экран · Зона: АЗ · Приоритет: Should
Версия: 0.2 · Дата: 2026-07-05
Источники: [Foundations](00-foundations.md) · [FR-026…028] · [US-015, US-016]
Сквозные правила – в `00-foundations.md`.

## 1. Назначение и контекст
Профиль клиента. На десктопе – центрированная карточка (ширина ~400px) с данными и настройками.
Минималистичен: показывает телефон (логин), даёт выход из аккаунта и переход к настройкам уведомлений.
Редактирование имени/телефона – не в MVP.

## 2. Пользователь и цель
Роль: Клиент.
Цель: проверить свои данные, настроить уведомления, выйти из аккаунта.

## 3. Навигация
Входящие: SCR-002 / SCR-005 (иконка профиля в хедере).
Исходящие:
- «Настройки уведомлений» → SCR-009.
- «Выйти» → SCR-001 (сброс сессии).
- Назад → предыдущий экран.

## 4. Контент-инвентарь
| Элемент | Источник | Назначение |
|---------|----------|------------|
| Телефон | user.phone | Логин клиента (readonly) |
| Статус подписки на push | settings | «Включены» / «Выключены» |
| Ссылка «Настройки уведомлений» | — | Переход на SCR-009 |
| Кнопка «Выйти» | — | Сброс сессии → SCR-001 |

## 5. Структура и иерархия (десктоп, карточка)
┌─────────────────────────────────────┐
│ Профиль │
│ ─────────────────────────────────── │
│ [аватар] │
│ +7 999 123-45-67 │
│ ─────────────────────────────────── │
│ Настройки │
│ 🔔 Уведомления › │
│ ─────────────────────────────────── │
│ [ Выйти ] │
└─────────────────────────────────────┘
- Карточка по центру, без фиксированных панелей.
- Аватар: круглое изображение 72px, заглушка с инициалами.
- Телефон: readonly, формат +7 XXX XXX-XX-XX.
- Кнопка «Выйти»: подтверждение через системный confirm (или сразу – за дизайнером).

## 6. Компоненты и поведение
- Ссылка «Настройки уведомлений» – переход на SCR-009.
- Кнопка «Выйти» – сбрасывает сессию, редирект на SCR-001.

## 7. Состояния экрана
| Состояние | Содержимое |
|-----------|------------|
| Content | Данные клиента + настройки + выход |
| Loading | Спиннер при загрузке профиля |
| Error | «Не удалось загрузить профиль» + «Повторить» |

## 8. Валидации и микрокопия
| Правило | Текст |
|---------|-------|
| Выход | «Выйти из аккаунта?» (если подтверждение) |
| Телефон | Readonly, формат +7 |

## 9. Доступность и адаптивность (десктоп)
- Аватар: 72px круг.
- Ссылка настроек: тач-зона ≥ 32px.
- Кнопка «Выйти»: тач-зона ≥ 32px.
- Адаптив: контейнер max-width 400px на планшете/десктопе; на мобильных – 90% ширины.

## 10. Критерии приёмки дизайна
AC-001 — Отображение телефона
  Дано: клиент авторизован
  Когда: открыт SCR-007
  Тогда: виден телефон в формате +7 XXX XXX-XX-XX

AC-002 — Переход к настройкам
  Дано: открыт SCR-007
  Когда: нажата «Настройки уведомлений»
  Тогда: открывается SCR-009

AC-003 — Выход из аккаунта
  Дано: открыт SCR-007
  Когда: нажата «Выйти»
  Тогда: сессия сброшена, открыт SCR-001

## 11. Решения
| # | Решение |
|---|---------|
| 1 | Редактирование имени/телефона – не в MVP. |
| 2 | Подтверждение выхода – на усмотрение дизайнера (системный confirm или сразу). |
| 3 | На десктопе – центрированная карточка. |
