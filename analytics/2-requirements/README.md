## Приоритеты

| Приоритет | Значение |
| --- | --- |
| **Must** | Must-have MVP или обязательный шаг для must-have сценария |
| **Should** | В скоупе поставки, но не в списке must-have MVP |
| **Won't** | Явно вне скоупа текущей поставки |
