# User Story (US)

| ID | Формулировка | Приоритет |
| --- | --- | --- |
| US-001 | **Как клиент**, я хочу войти по **телефону и SMS-коду**, чтобы получить доступ к записи на занятия | Must |
| US-002 | **Как клиент**, я хочу видеть **расписание слотов на 7 дней**, чтобы выбрать удобное занятие | Must |
| US-003 | **Как клиент**, я хочу **фильтровать занятия по программе**, чтобы найти подходящий мастер-класс | Must |
| US-004 | **Как клиент**, я хочу **фильтровать расписание по дате** (до месяца), чтобы спланировать визит заранее | Should |
| US-005 | **Как клиент**, я хочу видеть в карточке слота **время, программу, мастера, цену, свободные места, адрес и статус**, чтобы принять решение о записи | Must |
| US-006 | **Как клиент**, я хочу видеть **занятые слоты с пометкой «мест нет»**, чтобы понимать полную картину расписания | Should |
| US-007 | **Как клиент**, я хочу при отсутствии слотов видеть сообщение **«Пока нет доступных занятий»**, чтобы понимать, что записи сейчас нет | Should |
| US-008 | **Как клиент**, я хочу **записаться на занятие на себя** и сразу получить подтверждение, чтобы не ждать ответа владельца | Must |
| US-009 | **Как клиент**, я хочу выбрать **свои инструменты или прокат**, чтобы подготовиться к занятию | Should |
| US-010 | **Как клиент**, я хочу видеть **цену и доплату за прокат до записи**, чтобы знать стоимость визита | Should |
| US-011 | **Как клиент**, я хочу получить **понятное сообщение**, если мест уже нет, чтобы не думать, что запись прошла | Must |
| US-012 | **Как клиент**, я хочу **отменить бронь**, чтобы освободить место, если планы изменились | Must |
| US-013 | **Как клиент**, я хочу видеть **размер штрафа из системы** перед подтверждением поздней отмены, чтобы принять осознанное решение | Must |
| US-014 | **Как клиент**, я хочу видеть статус **«Отменено мастерской»** и причину, если занятие отменили по форс-мажору | Should |
| US-015 | **Как клиент**, я хочу получить **push-уведомление**, если мастерская отменила моё занятие | Should |
| US-016 | **Как клиент**, я хочу получать **напоминания о записи**, чтобы не забыть о занятии | Should |
| US-017 | **Как клиент**, я хочу **оценить мастера 1–5 звёзд** после занятия, чтобы дать обратную связь | Should |
